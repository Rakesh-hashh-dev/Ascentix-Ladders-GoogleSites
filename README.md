## 📌 Repository Overview

This repository contains the complete web architecture, deployment blueprints, responsive HTML/CSS embeds, and visual asset library designed for building the **Ascentix Ladders** official web presence on **[Google Sites](https://sites.google.com/)**.

It provides everything needed to deploy a high-converting, SEO-optimized, and brand-consistent industrial e-commerce showcase across 10 specialized product lines.

## 🛠️ Quick Start

### 1. Preview Standalone Prototype Locally
Open `index.html` or `advertisement_clip.html` directly in any modern browser:
```bash
# In PowerShell:
Start-Process index.html
```

### 2. Deploy to Google Sites
1. Follow the step-by-step instructions in [`NEW_PRODUCTS_IMPLEMENTATION_GUIDE.md`](NEW_PRODUCTS_IMPLEMENTATION_GUIDE.md).
2. Copy embed snippets directly from [`GOOGLE_SITES_EMBED_SNIPPETS.md`](GOOGLE_SITES_EMBED_SNIPPETS.md) into Google Sites **Embed > Embed code** widgets.
3. Upload product photography and color variants from the [`assets/products/`](assets/products/) directory.
